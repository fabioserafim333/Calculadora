# 🧮 Calculadora Tkinter

Uma calculadora gráfica minimalista desenvolvida em **Python** utilizando **Tkinter**.

Este projeto foi desenvolvido como parte dos meus estudos em Python e desenvolvimento de interfaces gráficas.

## 📸 Sobre o projeto

A aplicação possui uma interface simples e moderna, permitindo realizar operações matemáticas básicas através dos botões da interface ou do teclado.

## ✨ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- `%` Porcentagem
- `±` Alteração de sinal
- `AC` Limpar cálculo
- Suporte ao teclado
- Interface gráfica minimalista

## 🛠️ Tecnologias utilizadas

- **Python**
- **Tkinter**

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/calculadora-tkinter.git
```

### 2. Entre na pasta do projeto

```bash
cd calculadora-tkinter
```

### 3. Execute o programa

```bash
python calculadora.py
```

> O Tkinter normalmente já acompanha a instalação do Python, portanto não é necessário instalar bibliotecas externas para executar o projeto.
